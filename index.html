// resonance

Your requests,
your machine.

Local-first Zero account No telemetry Open source

One desktop app for REST, GraphQL, gRPC, WebSocket, MQTT, and SSE — built on Tauri. Your data stays on your machine: no cloud sync, no sign-in, no usage tracking. ~15MB to install, ~50MB RAM at runtime.

// 01 · tour

From the first request
to the CI run.

Import a spec, send and script requests, mock what is not built yet, and run the same collections headless. One window, your machine.

01

Send requests across six protocols

REST, GraphQL, gRPC, WebSocket, SSE and MQTT share one editor, one sidebar and one set of environments.

  • Auth per request, folder or collection: Bearer, Basic, API Key, OAuth 2.0 with auto-refresh, Digest, NTLM, AWS SigV4
  • Responses as trees, queried with JSONPath or XPath, validated against a JSON Schema
  • Timing split into DNS, TCP, TLS, first byte and transfer
  • Any request as code in cURL, Python, JavaScript, Node.js, Go, PHP, Ruby or Java
request editor
02

Switch environments, keep secrets out of git

Collections are plain files you can commit. Anything sensitive goes to the OS keychain instead.

  • Named environments, {{ variables }} anywhere, switched in one click
  • Secret values stored in Keychain, Credential Manager or Secret Service
  • Client certificates for mutual TLS and your own CAs, mapped per host
  • Request history and workspace tabs restored after a restart
environments
03

Mock what is not built yet

Import a spec and serve it locally before the backend exists.

  • Import OpenAPI 3.x, Swagger 2.0, Postman, Insomnia, HAR or a cURL command
  • Responses from your examples and schemas, with templates that echo the request
  • A Prefer header picks error responses on demand
  • Every hit shows up in the request log
mock server
04

Script it, then run it in CI

The runner you build in the app is the runner the command line executes.

  • JavaScript before and after each request, with HMAC and hashing built in
  • Most Postman pm.* scripts run unchanged
  • Collection runner with chained variables, delays and stop-on-error
  • Headless runs with JUnit reports and exit codes, plus a GitHub Action
ci

    --runner smoke --junit reports/junit.xml

05

Make it yours

Settings follow your desktop, not the other way round.

  • Light, dark or system theme with nine accent colours
  • English, Portuguese (BR), German, Spanish, French and Italian
  • HTTP, HTTPS or SOCKS proxy with auth and bypass lists
  • Platform-native shortcuts; Ctrl/Cmd+/ lists them

// 03 · download

Pick your platform.

Free and open-source. Runs entirely on your machine — no account, no sign-up, no strings.

linux

AppImage or .deb package. Also on Flathub, Snap, and the AUR.

Flathub flatpak install flathub io.github.db_mobile.resonance
Snap snap install db-mobile-resonance
AUR yay -S resonance-bin
Download for Linux
macos

Universal DMG for both Intel and Apple Silicon, or install via Homebrew.

Homebrew brew install db-mobile/resonance/resonance
Download for macOS
windows

NSIS installer for Windows 10 and above, or install via winget. No elevated permissions required.

winget winget install DBMobile.Resonance
Download for Windows
or build from source
bash 
$ git clone https://github.com/db-mobile/resonance.git
$ cd resonance
$ npm install
$ npm run build:tauri

Requires Tauri system dependencies.

or install the command line for CI
bash 
$ curl -fsSL https://raw.githubusercontent.com/db-mobile/resonance/main/install.sh \
    | sh
$ resonance run collections/petstore --runner smoke --junit reports/junit.xml

Linux and macOS; static binaries, verified against the release checksums. Windows and GitHub Actions: see the command-line guide.
